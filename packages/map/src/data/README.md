`equal-earth-countries.json` contains Natural Earth's public-domain 1:110m country
boundaries (177 features), with properties reduced to country names.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

Bundled with the lazy Equal Earth overview so it also works offline. Original
geographic coordinates are retained; spherical ring winding is normalized on
load for D3's projection and antimeridian clipping.
