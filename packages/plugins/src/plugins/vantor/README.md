# Vantor Open Data source

This directory vendors the framework-independent source from
[`opengeos/maplibre-gl-vantor`](https://github.com/opengeos/maplibre-gl-vantor)
version 0.2.1 (commit `187ae11`). GeoLibre's lifecycle wrapper lives one level
up in `maplibre-vantor.ts`. The upstream MIT license is included in `LICENSE`.
