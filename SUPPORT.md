# Getting help with GeoLibre

- **Documentation.** Start with the [User Guide](https://geolibre.app/user-guide/interface/),
  the [Tutorials](https://geolibre.app/tutorials/), and
  [Troubleshooting](https://geolibre.app/user-guide/troubleshooting/).
- **Questions.** Ask "how do I...?" questions in
  [GitHub Discussions (Q&A)](https://github.com/opengeos/GeoLibre/discussions/new?category=q-a),
  so answers stay searchable for the next person.
- **Bugs and feature requests.** Open an
  [issue](https://github.com/opengeos/GeoLibre/issues/new/choose) using the bug
  report or feature request template. For a bug, include steps to reproduce,
  what you expected and what happened, your operating system, and whether it
  happened on the web, desktop, mobile, or Jupyter build.
- **Security vulnerabilities.** Do not open a public issue. Report it privately
  through [GitHub security advisories](https://github.com/opengeos/GeoLibre/security/advisories/new).
- **Contributing.** See the [Contributing guide](https://geolibre.app/contributing/).

GeoLibre is maintained by volunteers. Issues and discussions are usually
answered within a few days, but there is no guaranteed response time. Everyone
taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
