## Default Permission

List paired Bluetooth GNSS receivers, stream NMEA from one, and feed it NTRIP corrections.

#### This default permission set includes the following:

- `allow-list-devices`
- `allow-connect`
- `allow-disconnect`
- `allow-start-corrections`
- `allow-stop-corrections`
